# UI / Game-Design Audit — 2026-08-24

Findings from a genuine fresh-save first-run, plus comparison against the genre
benchmarks already cited in `docs/design-principles.md` ("Premium Gacha-RPG
Grounding": Genshin Impact, Honkai: Star Rail, Arknights, Knights Chronicle) and
the roguelite/tactical lineage the combat now draws on (FTL, Slay the Spire).

Recorded so they aren't lost while other work proceeds. **Not yet fixed** — this is
a problem list, not a changelog.

## Confirmed by direct observation

1. **No title screen.** The game drops straight onto the star map with a dialogue
   overlay already open. Every commercial game in this space opens on an identity
   screen (logo, New Game / Continue, settings). Right now there is no moment that
   says what this game *is* before it starts happening, and no way to start over.

2. **Zero navigation affordance during story scenes.** `App.tsx` hides the ship
   console whenever a story scene is active — which is the entire opening. A brand
   new player's first screen has no visible controls at all.

3. **Dialogue presentation is the weakest screen in the game.** A thin bottom strip,
   small text, speaker name as plain coloured text, no portrait, no character art,
   no text animation. Compare against any of the four benchmark titles, where
   dialogue is a headline presentation layer with portraits, framing and motion.
   Emberwake's story is its most-developed content and its least-presented.

4. **Onboarding is a single line of grey 0.66rem text** ("拖动/点击以飞行…") under
   the map. There is no tutorial, no first-time callout, no progressive teaching of
   the console / ascension / rift systems as they unlock.

5. **The star map reads as empty.** A very large dark field with two small POI
   clusters. Benchmarks fill this space with parallax, ambient traffic, hazards, or
   simply a tighter playfield.

## Structural gaps vs. genre expectations

6. **No session-level goals.** No dailies, no "next milestone", no run summary.
   The meta loop (design-principles.md #4) has progression systems but nothing that
   tells the player what to aim at *this session*.

7. **No codex / encyclopedia.** Six acts of story, ten factions, and a growing
   module and crew roster with nowhere to review any of it. Standard in the genre.

8. **Combat has no speed control or auto-resolve.** Once fights become repeatable
   (bounties, rift farming) the lack of 2x / skip is a real friction — every
   benchmark ships one.

9. **No settings screen at all.** Mute and language are bare icons in the top bar;
   there's no volume, no text speed, no reset-save.

## Priority

Highest value first, by how much each affects a new player's first ten minutes:
title screen → dialogue presentation → onboarding → settings/codex → map density →
session goals → combat speed control.
